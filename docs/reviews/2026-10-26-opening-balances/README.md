# لقطات مراجعة PR B — أرصدة أول المدة

لقطات من معاينة المتصفح الحقيقية (`npm run preview:ui` → `http://localhost:4173`) بالعربية واتجاه RTL،
مولّدة بالأمر:

```bash
LD_LIBRARY_PATH=/tmp/nsslibs node scripts/preview/screenshots.mjs
```

المعاينة تعمل على `src/dev/preview/memorySupabase.ts` (بيانات في الذاكرة، بلا اتصال بـSupabase وبلا سجلات تدقيق).
البيانات المزروعة تتضمن رصيدين سليمين في «مخزن المواد الخام» ورصيدين يتيمين لتعريض قسم «أرصدة تحتاج مراجعة»:

| الملف                        | العرض | المحتوى                                                        |
| ---------------------------- | ----- | -------------------------------------------------------------- |
| `01-desktop-1280.png`        | 1280  | الشاشة كاملة: المحطات، لوحة المخزن، قسم المراجعة، أزرار المخزن |
| `02-mobile-390.png`          | 390   | نفس الشاشة على هاتف حقيقي، بلا تجاوز أفقي                      |
| `03-review-mobile-390.png`   | 390   | «أرصدة تحتاج مراجعة» مقرّبة: صفّا مراجعة للقراءة فقط           |
| `04-picker-mobile-390.png`   | 390   | المنتقي المضمّن (Combobox + شرائح) مفتوحًا على الهاتف          |
| `05-picker-desktop-1280.png` | 1280  | المنتقي على سطح المكتب مع البحث وقائمة التصنيفات المتاحة       |

الأرقام في هذه اللقطات لاتينية عن قصد (`ar-EG-u-nu-latn`)، لتطابق حقل `type="number"` المجاور لها.
