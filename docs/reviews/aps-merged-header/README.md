# دمج «نوع الخطاب» و«بيانات الخطاب» في فقرة واحدة — حزمة مراجعة

تعديل بنيوي على ترتيب شاشة إدخال الخطاب، مأخوذ من معاينة محلية ببيانات خيالية
(`npm run preview:aps`). لا SQL جديد، ولا تغيير في أي تحقق أو حساب أو حفظ.

## قبل

```
01  اختر نوع الخطاب        ← رأس مستقل + سطر تلميحي
    [ وارد ][ منصرف ][ تحويل داخلي ][ تحويل خارجي ]

02  بيانات الخطاب          ← رأس ثانٍ يقول الشيء نفسه
    [ فترة 4 ] 📅 أكتوبر  عام مالي 2026/2027
    رقم النظام (EPS)            كود الخطاب
```

رأسان لفكرة واحدة: الهيدر الرئيسي اللاصق يعرض النوع بالفعل، فسطر «اختر نوع
الخطاب» تحته كان تكراراً بصرياً يأكل مساحة قبل أن يصل القارئ إلى الفترة.

## بعد

```
01  بيانات الخطاب
    [ وارد ][ منصرف ][ تحويل داخلي ][ تحويل خارجي ]   ← Segmented Control
    [ فترة 4 ] 📅 أكتوبر  عام مالي 2026/2027           ← للقراءة فقط
    رقم النظام (EPS)            كود الخطاب
    [ 2458 ]                    [ YM ▼ ] : [ 63 ]
```

- **فقرة واحدة، ثلاثة أسطر مرتبة بترتيب عمل المستخدم:** قرار النوع ← معلومة
  الفترة ← إدخال EPS والكود. الفقرتان 01 و02 صارتا فقرة `01`.
- **النوع صار Segmented Control:** نفس الأزرار الأربعة في شريط واحد، لكن الشريط
  `@2xl:inline-grid @2xl:auto-cols-max @2xl:grid-flow-col` — يأخذ عرض نصوصه فقط
  (`≈760px` من أصل `1100px`) بدل أن يمتد على عرض الفقرة كأربع بطاقات.
  على الهاتف يبقى صفاً واحداً من أربعة أزرار متساوية الارتفاع (`44px`).
- **الفترة كما هي:** شارة `فترة N` + 📅 الشهر + العام المالي الباهت — نفس شريط
  PR #33 حرفياً، للقراءة فقط.
- **EPS والكود في سطر واحد:** ينتقلان إلى سطرين تلقائياً عندما يضيق العرض
  (`@xl` بدل `@2xl`)، فيظهر EPS فوق الكود على الهاتف بدل أن يتزاحما.
- **لا عناوين فرعية داخل الفقرة:** التلميح الوحيد هو تلميح الفقرة، وقد دُمج فيه
  معنى التلميحين القديمين («النوع يحدد الحقول…» من الفقرة المحذوفة).
- **الترقيم بعد الدمج (بلا تكرار):** `01 بيانات الخطاب` ← `02 الجهة` (كانت 03)
  ← `03 التفاصيل` (كانت 04). في التحويل الداخلي تُحذف «الجهة»، فلا يبقى إلا
  `01` ثم `02` للتفاصيل.

## ما لم يتغيّر

- الهيدر الرئيسي اللاصق ما زال يعكس اللون والأيقونة والنص حسب النوع لحظياً.
- شريط الفترة ما زال السطر الوحيد الذي يذكر الفترة، والفترة تُقرأ من الضبط
  الدوري (لا شيء يُكتب هنا).
- كود الخطاب ما زال `[ المُصدر ▼ ] : [ الرقم ]`، والنقطتان تُكتبان تلقائياً.
- التحقق والتجميد بعد الاعتماد والحفظ والاعتماد و`p_letter_date` كما هي.
- الفقرة 03 (جهة/غرض الصرف/الشركة) والفقرة 04 (التفاصيل) بلا تغيير في الحقول.

لإعادة الالتقاط (بعد `npm run preview:aps` على المنفذ 4174):

```bash
CHROME_PATH=/tmp/chromium LD_LIBRARY_PATH=/tmp/nsslibs node scripts/preview/merged-header.mjs
```

السكربت لا يلتقط فقط: يتحقق أن الشريط فوق شريط الفترة وأن شريط الفترة فوق
الحقلين، وأن الأزرار الأربعة صف واحد أقصر من `60px` وأضيق من شريط الفترة، وأن
عنوان «اختر نوع الخطاب» لم يبق له أثر، وأن الفترة لم تتغيّر.
